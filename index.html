IoT-Based Grain Drying System

An academic capstone project that combines a physical grain-drying prototype with a software application. The system involves humidity sensing, fan control, and application functions for account access and database integration.

Project objectives

  • Develop a system that supports the grain-drying process.
  • Connect sensor readings and hardware components with the application.
  • Explore predictive approaches for estimating grain moisture behavior.

Technologies and components

IoT Hardware Humidity Sensing Fan Control Database Integration Login System Random Forest Gradient Boosting Modified Chung–Pfost EMC
